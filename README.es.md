Un demake de **Just Shapes & Beats**, de **Berzerk Studio**, hecho por un fan para aprender PICO-8. Es un proyecto sin fines comerciales.

## Lo que falta

- Componer música en PICO-8 y crear niveles a partir de ella.
- Publicar el cartucho en la página de PICO-8.

## Contribuir

¿Quieres aportar música o crear un nivel? Toda ayuda es bienvenida. La [guía de niveles](DOC_LEVELS.md) explica cómo crear tus propios niveles.

La [licencia MIT](LICENCE) cubre únicamente el código original escrito para este proyecto. La música, los gráficos y las marcas del juego original pertenecen a sus respectivos propietarios.
