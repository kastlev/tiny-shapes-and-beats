A fan-made demake of **Just Shapes & Beats** by **Berzerk Studio**, made to learn PICO-8. This is a non-commercial project.

## What's next

- Compose music in PICO-8 and build levels around it.
- Publish the cartridge on the PICO-8 website.

## Contributing

Want to contribute music or create a level? Contributions are welcome. The [level guide](DOC_LEVELS.md) (in Spanish) explains how to build your own levels.
